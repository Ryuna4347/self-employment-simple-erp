# Costs 도메인 (비용 관리)

## 개요

관리자(ADMIN) 전용 비용 관리 기능입니다. 연/월별로 업무 비용을 기록하고 조회합니다.

### 핵심 기능
- 월별 비용 목록 조회 (연/월 필터)
- 비용 CRUD (날짜, 제목, 금액, 비고)
- 고정비용 관리 (이름, 금액, 주기) — 향후 크론으로 자동 Expense 생성 예정
- 대시보드 총 비용 카드에 합산 반영

---

## 데이터 모델

### Expense
- `date`: 비용 발생 날짜 (사용자 입력)
- `userId`: 작성자 (관리자)
- `title`: 비용 제목
- `amount`: 금액
- `description`: 비고 (선택)
- `isAutoGenerated`: 자동 생성 여부 (고정비용 크론에 의해 생성된 경우 true)
- `createdAt`, `updatedAt`: 자동 관리 (목록에 미노출)

### RecurringCost (고정비용)
- `name`: 고정비용 이름
- `amount`: 금액
- `frequency`: 주기 (WEEKLY=매주 월요일, MONTHLY=매월 1일)
- `isActive`: 활성 상태 (크론 대비)
- `createdAt`, `updatedAt`: 자동 관리

---

## 비즈니스 규칙

- 관리자만 비용 생성/수정/삭제 가능
- 비용 합계는 대시보드의 조회 기간에 맞춰 집계

## 관련 API

- `GET/POST /api/admin/costs` - 비용 목록/생성
- `PUT/DELETE /api/admin/costs/[id]` - 비용 수정/삭제
- `GET/POST /api/admin/recurring-costs` - 고정비용 목록/생성
- `PUT/DELETE /api/admin/recurring-costs/[id]` - 고정비용 수정/삭제
- `POST /api/cron/generate-recurring-costs` - 고정비용 자동 생성 (크론)
